# Folder structure
Folders are meant to be big buckets of notes. [[🧠 Growing this Brain|🪴 This Brain]] has:

- `⚙️ Meta` for notes and tools to handle this Obsidian vault.
    - `📎 Attachments` contains all the file attachments
    - `📐 Templates` for Obsidian templates
- `🌱 Seedbox` for notes whose location is not yet clear, scratchpads, quick writedowns of ideas…
- `⚜️ Cortex` for Evergreen notes. Most notes of the Brain live here. Create folders ONLY if absolutely needed 
- `💧 Sources` for Literature notes on books, courses, videos…
- `🎟️ Kanban` for Kanban boards
- `📌 Draw` for Excalidraw files - make sure these are properly embedded in a relevant note
- `📓 Journal`  for writing your daily thoughts
- `🕸️ Indexes` for creating strong indexed links
